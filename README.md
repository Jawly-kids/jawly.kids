# Jawly website

This is the standalone public website. The Heroes landing page lives at `/heroes` in `app/heroes`, with its media in `public/heroes`.

Run `pnpm install` and `pnpm dev` to preview it locally. The root page is a temporary index for the future Jawly homepage. The Heroes demo request currently opens a prepared email to `kyle@jawly.kids`; online scheduling awaits the Calendly link.
